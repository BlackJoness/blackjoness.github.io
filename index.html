Agência 24/7

Site, propostas e modelo de medição2026, agência que cofundei. agencia24por7.com

Desenhei o visual e construí o front do site do zero, com deploy automático por GitHub Actions. A página vende quatro serviços com uma tese só: o agente de IA ajusta o que está dentro do combinado, mudança de estratégia passa por um especialista e mais verba só entra com o ok do cliente.

Também estruturei a medição de resultado dos clientes de tráfego: pixel, API de conversões, tag do Google Ads e GA4, painel de acompanhamento, relatório semanal e meta de leads calculada a partir do CAC, revista mensalmente. Os primeiros clientes estão em onboarding.

Wayne Industries

2026, controle de acesso e gestão de recursos, no ar

O enunciado tinha três páginas e nenhuma especificação técnica. Transformei cada frase em requisito com critério de aceite, defini o que ficaria de fora e registrei as decisões em seis ADRs.

O código foi escrito com Claude Code. Antes da entrega fiz uma revisão de segurança em duas frentes: o que eu mesmo encontrei lendo o código e o que pedi à IA para apontar. Cada achado eu validei e decidi se entrava: o token que carregava o cargo, o painel que devolvia o mesmo payload para todo perfil e o CORS que recusava a origem da Vercel.

API em Node, PostgreSQL, React, 52 testes automatizados e integração contínua. Autorização decidida no servidor, não na tela.

Entre em wayne-industries-web.vercel.app com bruce@wayne.com e a senha Wayne@123 para o perfil de administrador; alfred@wayne.com mostra o de funcionário. A API hospeda em plano gratuito e a primeira abertura pode levar um minuto. Código em github.com/BlackJoness/wayne-industries.

# um funcionário tentando excluir um recurso, sem passar pela interface
curl -X DELETE https://wayne-api-1vh8.onrender.com/api/v1/resources/ID \
  -H "Authorization: Bearer TOKEN_DE_FUNCIONARIO"

# resposta da API
HTTP/1.1 403 Forbidden
É tentador tratar controle de acesso como problema de interface: esconder o botão de excluir de quem não é administrador e considerar o requisito cumprido. Qualquer pessoa com um cliente HTTP derruba essa proteção em trinta segundos.ADR 0004, “A autorização vive no backend”, do repositório do projeto
O token guarda apenas a identidade. Cargo e situação são carregados do banco a cada requisição, para que rebaixar ou desativar um usuário tenha efeito imediato em vez de esperar o token expirar.comentário em src/shared/utils/jwt.ts, escrito após a revisão de segurança

Uso Claude Code e Claude Projects com servidores MCP (Chrome, Figma, Linear, GitHub) para revisar código, organizar backlog e automatizar tarefas repetidas no navegador. Na 24/7, desenhei e documentei os serviços de agente de atendimento com IA para site e WhatsApp e de implantação de CRM no RD Station; a primeira implantação com cliente ainda não começou.
